# Layer4: Action - เสน่ห์เงียบทรงพลัง: Passive Attractive ฉบับผู้หญิง INFJ

**Content Writing**
* แนวทางการเขียนจะเน้นการบรรยายที่ให้ความรู้และสร้างความเข้าใจ ผสมผสานระหว่างทฤษฎีบุคลิกภาพ MBTI (โดยเฉพาะการทำงานของฟังก์ชันต่างๆ ใน INFJ) และหลักการจิตวิทยาจากหนังสือ The Art of Seduction 
* จัดรูปแบบเนื้อหาด้วยโครงสร้างแบบ RWP (Rich Text with Picture) เพื่อให้อ่านง่ายและดึงดูดความสนใจ ดังนี้:
  * ใช้ **ตัวหนา (Bold)** เพื่อเน้นย้ำประเด็นหลักและใจความสำคัญ
  * ใช้ *ตัวเอียง (Italic)* เมื่อกล่าวถึงคำศัพท์เฉพาะทาง ทฤษฎี หรือศัพท์ภาษาอังกฤษ
  * ใช้ Bullet / List เพื่อจัดระเบียบข้อมูลเป็นข้อๆ ทำให้ผู้อ่านย่อยข้อมูลได้ง่ายขึ้น
  * ใช้ ตาราง (Table) ในการเปรียบเทียบข้อมูลหรือสรุปประเด็นเนื้อหา
  * ใช้ Callout Box พร้อม Icon (เช่น >💡 ข้อสังเกต : ...) เพื่อเสริมเกร็ดความรู้ ข้อคิด หรือคำแนะนำเพิ่มเติม

**Visual**
* แทรกรูปภาพประกอบเนื้อหาเพื่อเสริมความเข้าใจ โดยกำหนดอัตราส่วนภาพที่ 16:8 สไตล์ Minimal และใช้พื้นหลังสีขาว
* การระบุรูปภาพจะเขียนในรูปแบบ Prompt ภาษาอังกฤษ ตัวอย่างเช่น `[PROMPT: A minimal 16:8 illustration of...]`
* ในกรณีที่เป็นรูป Educational Infographic คำสั่ง (Prompt) จะเป็นภาษาอังกฤษ แต่จะมีการระบุเงื่อนไขอย่างชัดเจนว่า **เนื้อหาข้อความในรูปจะต้องเป็นภาษาไทยทั้งหมด**
* รูปแบบของ Infographic ที่สามารถนำมาปรับใช้ได้ ได้แก่:
  * *Informational Infographic:* เน้นข้อความและไอคอน จัดเรียงจากบนลงล่าง
  * *Process Infographic:* แสดงขั้นตอนการสร้างเสน่ห์โดยใช้ลูกศรเชื่อมโยงเป็นลำดับ 1-2-3
  * *Grid Infographic:* แบ่งข้อมูลออกเป็นส่วนๆ (Card) ในขนาดที่เท่ากัน เพื่อแสดงองค์ประกอบต่างๆ
  * *Hierarchy / Pyramid Infographic:* แสดงลำดับความสำคัญของฟังก์ชันทางจิตวิทยาจากฐานสู่ยอด
