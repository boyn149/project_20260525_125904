# Layer4: Action - กลไกปิดตายความรู้สึก: เจาะลึกปรากฏการณ์ Door Slam ของ INFJ

**Content Writing**
* เน้นการเขียนอธิบายเชิงจิตวิทยาและทฤษฎี MBTI อย่างเป็นเหตุเป็นผล โดยเจาะลึกที่การทำงานของฟังก์ชันทางจิตวิทยาของ INFJ (เช่น การดูดซับอารมณ์ผ่าน Extraverted Feeling และการสะสมความเครียดจนตกอยู่ในสภาวะสับสนของ Inferior Extraverted Sensing) เพื่ออธิบายกลไกการเกิด Door Slam
* ใช้โครงสร้างการเขียนแบบ RWOP (Rich Text without picture) โดยเน้นการจัดระเบียบเนื้อหาด้วยตัวอักษรและการจัดหน้ากระดาษให้อ่านง่าย ชัดเจน ดังนี้:
  * ใช้ **ตัวหนา (Bold)** เพื่อเน้นย้ำคำสำคัญ อาการ หรือจุดเปลี่ยนทางอารมณ์ที่เป็นใจความหลัก
  * ใช้ *ตัวเอียง (Italic)* สำหรับคำศัพท์เฉพาะทางจิตวิทยา ทฤษฎี หรือฟังก์ชันของ MBTI (เช่น *Introverted Intuition*, *Grip stress*)
  * ใช้ Bullet / List เพื่ออธิบายลำดับขั้นตอนของการสะสมความรู้สึก สัญญาณเตือน และกระบวนการตัดความสัมพันธ์ให้เห็นเป็นข้อๆ
  * ใช้ ตาราง (Table) เพื่อเปรียบเทียบพฤติกรรม สภาวะอารมณ์ปกติ กับสภาวะเมื่อเกิดความกดดันจนถึงขีดจำกัด
  * ใช้ Callout Box แบบมี icon ตามรูปแบบ `>{icon} {bold_topic} : {content}` (เช่น >⚠️ **สัญญาณเตือน** : ...) เพื่อเน้นย้ำข้อควรระวังหรือจุดสังเกตก่อนที่จะเกิดการตัดความสัมพันธ์

**Visual**
* เนื่องจากหนังสือเล่มนี้ถูกกำหนดเงื่อนไขให้ใช้รูปแบบ RWOP จึงจะไม่มีการแทรกรูปภาพ ภาพวาด หรืออินโฟกราฟิกใดๆ เข้ามาในเนื้อหาอย่างเด็ดขาด
* การนำเสนอเชิงภาพ (Visual presentation) จะพึ่งพาการจัดรูปแบบโครงสร้างข้อความ (Text Formatting) เป็นหลัก เช่น การใช้สัญลักษณ์ Icon ประกอบ Callout Box, การจัดสัดส่วนของตาราง และการลำดับ Heading เพื่อสร้างจุดพักสายตาและทำให้ผู้อ่านสามารถจดจ่ออยู่กับเนื้อหาเชิงลึกได้อย่างเต็มที่โดยไม่รู้สึกว่าเนื้อหาอัดแน่นจนเกินไป
