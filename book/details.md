# Philosophy 
หนังสือเล่มนี้ตั้งอยู่บนปรัชญาที่ว่าเสน่ห์ที่แท้จริงไม่จำเป็นต้องเกิดจากการเป็นฝ่ายรุกเสมอไป แต่สามารถสร้างขึ้นได้จากพลังความสงบและความลึกลับที่ซ่อนอยู่ภายในตัวผู้หญิง INFJ โดยการผสานความเข้าใจเรื่องบุคลิกภาพ MBTI เข้ากับหลักจิตวิทยาและศิลปะแห่งการดึงดูด (Art of Seduction) เพื่อให้ผู้อ่านตระหนักถึงคุณค่าในตัวเอง ดึงดูดผู้อื่นด้วยความเป็นธรรมชาติ และสร้างความสัมพันธ์ที่ลึกซึ้งได้อย่างแยบยล

# Objective
1. เพื่อให้รู้กลไกการสร้างเสน่ห์ของผู้หญิง infj แบบไม่ต้องเป็นฝ่ายรุก
2. เพื่อให้รู้ทันตัวเอง
3. เพื่อให้สามารถดึงดูดคนที่รักได้

# Constrain
1. เนื้อหาต้องมีการพูดถึง type ของ mbti
2. จำนวณ 1 บท 2 หัวข้อย่อย
3. มีการเอา art of seduction เข้ามา
4. มีรูปแทรก
5. ใช้ RWP

# Philosophy 
หนังสือเล่มนี้มุ่งเน้นการทำความเข้าใจกลไกการป้องกันตัวทางจิตวิทยาของ INFJ หรือที่รู้จักกันในชื่อปรากฏการณ์ "Door Slam" ซึ่งเป็นปฏิกิริยาที่เกิดจากการสะสมความรู้สึกและการก้าวข้ามขีดจำกัดของความอดทน โดยมีเป้าหมายในการอธิบายกระบวนการนี้ผ่านมุมมองของทฤษฎี MBTI เพื่อให้ผู้คนสามารถตระหนักรู้ในตัวเอง เข้าใจรูปแบบการประมวลผลทางอารมณ์ และสามารถรับมือกับกลไกการตัดจบความสัมพันธ์ได้อย่างมีสติ

# Objective
1. เพื่อให้รู้กลไกการ door slam ของ infj
2. เพื่อให้รู้ทันตัวเอง

# Constrain
1. เนื้อหาต้องมีการพูดถึง type ของ mbti
2. จำนวณ 1 บท 2 หัวข้อย่อย
3. ไม่มีรูป
4. ใช้ RWOP
